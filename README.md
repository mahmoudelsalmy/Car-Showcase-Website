# 🚗 Car Show Case Website

A responsive web-based project for showcasing luxury cars.  
The website allows users to browse different car brands and models with their details and prices.  

---

## ✨ Features
- 🏎️ **Car Catalog**: Display of luxury car brands (Audi, Bugatti, Lamborghini, Ferrari, etc.) with images and details.  
- 🔍 **Search Functionality**: Search bar to quickly find cars.  
- 🌍 **Country Selector**: Dropdown menu for choosing a country.  
- 👤 **User Authentication (UI)**: Login modal with username & password.  
- 📱 **Responsive Design**: Built with **Bootstrap** for mobile and desktop support.  
- 📧 **Contact Section**: Quick access to contact developer via email.  

---

## 🛠️ Technologies Used
- **HTML5** – Structure and content  
- **CSS3 & Bootstrap** – Styling and responsive design  
- **Font Awesome & Google Fonts** – Icons and typography
